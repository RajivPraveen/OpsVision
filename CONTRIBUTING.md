# Contributing

Thanks for helping improve OpsVision. Small fixes and clear explanations are welcome.

1. Open an issue that describes the problem or change.
2. Create a branch and make the smallest useful change.
3. Run the checks: python3 -m unittest discover -s tests -v.
4. If you changed the dashboard, check it in a browser at both desktop and narrow widths.
5. Update the relevant guide and screenshot when behavior or wording changes.
6. Open a pull request with what changed and how you checked it.

Please use fictional or openly licensed data in issues, tests, screenshots, and pull requests. Do not include company records, credentials, or access tokens.
